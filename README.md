# 🎵 Music Genre Machine Learning Classifier
A simple machine learning project that predicts **music genres** based on input features like **age** and **gender**. Built using `pandas` and `scikit-learn` to train a **Decision Tree Classifier** and visualize the model.

## 🎯 Purpose
- **Train a model** to classify music genres.
- **Use machine learning** to make predictions based on input data.
- **Visualize** the decision-making process using a decision tree.

## 🛠 Methods & Technologies
- **Dataset**: `music.csv`
- **Libraries Used**: `pandas`, `scikit-learn`
- **Machine Learning Model**: Decision Tree Classifier
- **Visualization**: Decision tree saved as `.dot` and `.svg`

## 📊 Visualization
The decision tree visualization provides insight into the model's decision-making process.

## 🚀 How to Use
1. Install dependencies:
   ```bash
   pip install pandas scikit-learn
   ```
2. Run the Jupyter Notebook:
   ```bash
   jupyter notebook MusicAPP.ipynb
   ```
3. **Train the Model** and **Visualize the Decision Tree**.
